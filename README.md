# Business Calculator: Tape & GT

A large-key business calculator for Android by HomiLabs. The whole calculation stays on screen
(e.g. `2 + 2 + 2 + 2 + 2 + 2 − 6 × 4`) with the total in large figures, plus M+ / M− / MR / MC,
Grand Total, TAX+ / TAX−, business percent and a saved, shareable tape. Daylight theme, no login,
no permissions, works offline.

- Build: `flutter build appbundle --release`
- Tests: `flutter test`
- Store graphics: `flutter test tool/store_screens_test.dart && flutter test tool/make_graphics_test.dart`

Privacy: https://tools.homilabs.org/privacy#businesscalc
